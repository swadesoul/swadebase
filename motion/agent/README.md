# Kinetta — Motion Graphics Agent package

One agent, one job: SWADEBASE Motion Studio. Drop her into any agent program.

## Files
- `motion-agent.mjs` — persona, guardrails, tool schemas, built-in style picker, LLM prompt + validator (no dependencies).
- `agent.manifest.json` — generated by `node motion/styles/build.mjs`; the same data as JSON for hosts that can't import ESM.

## Option A — MCP (works everywhere: SSS Brain, Claude, ChatGPT, Sovereign Board)
```
URL:     https://swadebase.cloud/functions/v1/motion-studio/mcp
Auth:    Authorization: Bearer <SWADEBASE user access token>
Tools:   motion_list_styles, motion_recommend_styles, motion_create_project, motion_get_project, motion_list_projects
```
Example call:
```json
{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"motion_create_project",
 "arguments":{"mode":"idea","title":"Black Tales trailer","idea":"...","style_id":"auto","format":"9:16","duration_sec":20}}}
```
`motion_get_project` returns `downloads.video` and `downloads.source` once `status` is `ready`.

## Option B — SSS Brain Agent OS (Workforce role)
Register a worker with:
- role: `AGENT_MANIFEST.role`, persona: `AGENT_MANIFEST.persona`, guardrails: `AGENT_MANIFEST.guardrails`
- tools: `AGENT_TOOLS` mapped to the MCP connection above (risk class: low for list/recommend/get; spending for create because it queues a render)
- success criteria: project `status = ready` and both download links present

## Option C — the Grok-style agent adapter area
Load `agent.manifest.json` as the agent definition and point its tool adapter at the MCP URL. If the host speaks OpenAI-style function calling, each tool's `input_schema` is a valid JSON Schema `parameters` object.

## Behavior contract
1. Offer 3 picks with one-line reasons, recommend one.
2. "You pick" → choose and say why in one sentence.
3. Never invent a style id.
4. Always finish with downloadable MP4 + source ZIP.
