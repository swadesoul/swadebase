State: NEW DESIGN / APPROVED DIRECTION, NOT DEPLOYED
Purpose: reusable, customer-specific agent packages that can be sold with any founder-approved SWADEBASE white label as an upsell, with tenant-safe execution, cost guards, and a product-specific trained agent team.

Template fields: role_id, industry_pack, version, display_brand, description, relevant approved features, tools, read_scopes, write_scopes, approval_class, knowledge_source_ids, privacy boundary, owner_id, tenant_id, source_site_id, safety/regulated guardrails, worker route, language/voice controls, accessible UI presentation, cost ceiling by job/day/month, concurrency, metrics, evidence, test suite, rollback.

## User purchasing flow
At white-label checkout: choose source site and features; "Add your AI Team" presents default roles as employees described in plain language, with examples of tasks, initial/annual/monthly pricing, inclusive budgets and extra usage. Customer optionally swaps specialty agents. Customer must be able to buy later from admin Agent Store, not required at initial checkout.
After purchase: COS gathers business bio/goals, staff approvals, branding, compliance, preferred working hours, customer service policy and permitted data, then creates ONLY allowlisted read-only or draft agents first. Show training preview/evaluation for owner acceptance. Activate bounded tools/recurring jobs after scoped approval and test receipts. Site and SSS Brain parent dashboards receive only appropriately permitted status, count, usage, revenue and operational metrics, not unrestricted customer message contents.

## Cost & business protections
Target >=60% contribution margin, default 80%, up to 90% for efficient bundles. Calculate net revenue excluding tax, refunds and pass-through provider charges. Costs include payment, training amortization, inference, embedding/memory, voice, media generation, GPU worker, support, scheduled checks, browser sessions, storage, retries, monitoring and affiliate commission where applicable. Merchant/customer chooses direct BYO billing or quoted SWADE funded metered usage. Hard-stop when prepaid allowance exhausted; no secret cross-account fallback; compare by product and tenant weekly.
Affiliate network may promote agent bundles only if SKU commission + service cost preserve margin. White-label customer's own Affiliate Center remains separate merchant scoped.

## Acceptance before release
Product manifest exists and rights checked; one agent with no permissions can't act; two customer tenants cannot read each other's memory, files or secrets; a disabled license rejects tool calls; a selected persona DOES NOT grant worker access; simulated malicious prompt cannot change backend grants; approved task uses short-lived signed lease, budget, idempotency, logs and owner decision; expired approval denies action; signed billing webhook permits an actual grant only after reconciled payment; refund/cancel/grace acts correctly; cost cap enforces; alert and fallback; iPad voice when sold; restore and rollback; product's own help guide and role training.
No database migrations, deploys, purchases, payments, emails, client agents, roles or tool rights changed by this planning document.
