## Requested behavior and staged implementation
The native module station_libraries.py adds plan-authorized separate libraries and independent broadcast stations. Modes are private (own uploads only), catalog (explicit Maestro imports), and mixed. Each new station starts empty with an independent Music playlist, draft status and no flagship fallback. Ownership, library mode, active grant, file size, station count, aggregate bytes and track count are checked server-side. Plan grants are superadmin-only, expiring and service-only. Customer browser code cannot grant itself a plan.

Bulk upload creates a station/category folder and an engine playlist with regular rotation, every-N-songs inserts, or a daily time slot in America/Chicago. Categories are music, ad, bumper, liner and show. Audio and MP4 are decoded by ffprobe/ffmpeg. Each file is bounded at 80 MiB; originals are integrity-verified in existing Backblaze storage, with engine broadcast copies assigned to the selected station playlist and membership read back. Upload IDs prevent duplicate submissions. Failed/uncertain operations remain needs_review; they are not blindly resubmitted. Per-file status is shown. AI DJs use the existing station-specific queue/facts mechanism; non-music inserts carry the existing Maestro Radio marker so they are not announced as songs.

Saved SFTP logins list host, port and username after the credentials dialog closes. Passwords are not stored in the UI or returned in later lists. Separate-field copy, whole-login copy, text-selection fallback and explicit download are available. Reset uses the installed engine’s singular /sftp-user/{id} route. SFTP writes are founder-only because raw SFTP bypasses per-plan browser upload metering. Local engine source explicitly requires local media storage for SFTP: vault-backed flagship media cannot use that feature; browser bulk upload supports it without changing the broadcast storage.

The existing DJ function remains a compatibility adapter: create/list/SFTP route to the native host API; legacy sharing into managed libraries is denied to prevent bypassing mode and quota checks. A new versioned worker is prepared, with exact legacy-route forwarding. Existing assistant and live lyrics code is preserved.
