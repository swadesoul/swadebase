# Brainiak interface preservation contract — 2026-10-26

The voice-first redesign changes how people enter and navigate Brainiak. It does not authorize removing capabilities or replacing the SSS Brain / SWADEBASE ecosystem.

## Existing flows retained

Google sign-in through SWADEBASE, account-scoped memory and tasks, Chief of Staff conversation, briefing, activity, workspace export, connection and channel setup, approved-answer website widget, WhatsApp/Telegram setup, privacy controls, account controls, update marketplace, founder CMS, and the 720p explainer film remain available. The desktop conversation now has an optional adjacent panel showing existing tasks and knowledge. The live founder operator token propagation is preserved.

## Public demo delivered separately

An explicitly guided first-name and goal introduction uses native SWADEBASE Kokoro speech and the existing private Whisper transcription path. It creates no account or project, makes no payments, executes no external tools, and never substitutes paid voices. Typed input remains available. Temporary audio is deleted. Origin, request size, recording duration, concurrency and rate limits apply. This demo is not evidence that every planned agent workflow is complete.

## Product requirements retained for implementation

- Personal, Business and Enterprise experiences; Chief of Staff manages information and tells users which connection is missing.
- Persistent responsive projects, artifacts, websites, images, books, recipes, contracts, recorded-conversation analysis and native Voice Studio conversation.
- Reuse existing SWADEBASE connectors and adapters first; account connections, Gmail, Drive/calendar, creative tools, GitHub/development tools, MCP onboarding and founder-added connectors.
- Private credential entry inside the app; never put secrets into ordinary conversations, logs or generated public artifacts.
- Personal uses platform services. Eligible Business and Enterprise customers may bring keys. A single supported LLM provider must suffice; no forced second provider.
- Quotes before chargeable work, quality choices, own-provider versus platform cost comparison, usage limits, cost reservations and Stripe prepayment for out-of-plan work.
- Private workspace data/storage included in the main plan. Additional dedicated database environments are paid add-ons requiring real isolation and provisioning work.
- Security and routine operational updates included. Optional paid product/system updates are $49.99; purchased/free entitlements control automatic account updates.
- Founder administration includes gifted plans/credits and audited user/plan support views; impersonation must preserve access controls and audit trails.
- White-label/reseller package: $5,000 initial year, $500 annual renewal thereafter, customer pays infrastructure/provider usage separately. Installments and tenant suspension require explicit billing states; customer data remains protected and export/recovery rules need definition.
- Monitoring, incident diagnosis, qualified remediation, backups and restoration through the existing OATHLOOM / SSS Brain / SWADEBASE orchestration, Playwright and Restic capabilities where verified.
- Industry-specific knowledge and organization/employee management; medical workflows require a separately verified healthcare-ready deployment, appropriate providers and agreements. Uploading documents or locking a folder alone never establishes HIPAA compliance. Do not accept PHI into this public demo.

These requirements are preserved, not all declared implemented. Each needs verified adapters, permissions, usage economics and end-to-end acceptance checks before release. The interface must expose truthful availability and setup states.
