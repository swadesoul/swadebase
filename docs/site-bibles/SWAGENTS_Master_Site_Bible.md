# SWAGENTS — Master Site Bible
**Established as a planned separate product:** 2026-11-14 UTC
**Meaning:** SWADE + AGENTS = SWAGENTS
**Public site deployment:** LIVE public preview at https://swagents.live/ (https://www.swagents.live/ redirects to the apex). Domain, DNS and TLS are verified. This is not a fully activated paid SaaS: checkout, phone provisioning, and Rakazo/worker execution remain off.

## Product identity
SWAGENTS is the premium, original, voice-first agent platform for people and organizations. The front end feels like conversing with a smart, approachable person. It uses original SWADE branding and a persistent metallic voice orb with live speak/listen/think/interrupt states. It borrows useful interaction patterns without copying proprietary code or brand assets. No overlong spoken responses by default. Users create specialized agents and blend skills in a Fusion Builder.

## Architecture — reuse rather than duplication
SWADEBASE: canonical credentials, identity, permissions, databases, API adapters, quotas, deployment locks, billing and owner controls.
SSS Brain: persistent knowledge, company portfolios, approved Site Bibles, goals and memory. Every response distinguishes indexed source knowledge from verified live facts.
Brainiak: agent packaging, consumer and business templates, customer upgrade opportunities.
Rakazo: existing worker, task and computer services running on SWADEBASE-2. An authenticated, scoped execution bridge MUST be verified before unattended computer use and external actions.
SWOSTing: optional hosted deployment layer for customers; no second identity database.
SWADE Voice: existing local CPU Whisper STT and Kokoro TTS; bounded model calls via configured provider when needed.
Backblaze B2: durable media, metadata in SWADEBASE. No new paid platform required to begin.

## User experience
- One main conversational screen, voice orb always visible, simple short spoken replies, automatic pause after 3 seconds (configurable 1–5), up to 120 seconds per recording, voice interruption permission and stop button. iPad Safari verified for UI simulation; physical user acceptance required on new site.
- Side features: Agent Fusion, Spaces, Tasks & Approvals, Computer Studio with actual lease and takeover controls, Revenue Director, Knowledge Sources, Connections Hub and clear account controls.
- Five first presets: Chief of Staff, Artist/Label Manager, Personal Companion, Developer/Site Engineer, Sales & Marketing. Each agent has Soul/personality, voice, instructions, cost limits, skills, memory boundary and per-site permissions.
- Connections: GitHub private read adapter (scoped app, not yet verified in runtime), authorized X/Instagram/Facebook, email through Mail Machine/Postal, opt-in SMS/WhatsApp/Apple messaging only where supported. No fake integration badges.
- Brief dashboard: daily top-three cross-site revenue opportunities, evidence, free-first solution, KPI, approval state, verified rollout receipts.
