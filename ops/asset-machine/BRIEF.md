# Asset Machine
Audience: owners of financial instruments and digital assets, invited reviewers, administrators.
Goal: create an evidence-backed project, then obtain an independently approved review.
Primary action: Start an asset review.
Design: obsidian, copper, restrained teal; cinematic vault hero and existing generated copper logo.
Journey: introduction → asset categories → interactive five-stage explanation → oracle scope → legal review → create project.
Sources: founder requirements and inspected Asset Review code. No testimonials or invented verification.
Reuse: existing adapter process, GoTrue Google broker, local AI/voice, OCR, encrypted B2 transport. Separate machine_ tables, cookie path, storage prefix and HMAC-derived key.
Do not claim physical issuer verification, valuation, on-chain reserve monitoring, financing or minting are connected.
